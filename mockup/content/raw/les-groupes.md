# Les groupes — https://www.vcmp91.fr/les-groupes

**Main Heading:** "Les groupes du club"

**Introduction:** The club contains 4 groupes cyclistes (4 cycling groups). New members should contact group captains via email and request WhatsApp group access for weekend updates.

## Groups

1. **Groupe 1** — fastest, ~27/30 km/h, 75-110 km. Captain: Ludovic Terreil (ludovic.terreil@gmail.com)
2. **Groupe 2** — moderate, ~25/27 km/h, 75-110 km. Captain: Pascal Millot (pascal.stone@orange.fr)
3. **Groupe 3** — relaxed, ~22/25 km/h, 60-100 km. Captain: Jérôme Pourbaix (jerome.pourbaix@gmail.com)
4. **Groupe 4** — leisurely, ~20/22 km/h, contemplative, 50-90 km. Captain: Hervé Riou (herve.riou0@gmail.com)
